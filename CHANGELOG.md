# Pocket Studios — Changelog

## v1.0.0 (Initial Release)
### Features
- 🎬 Multi-track timeline editor (video + audio + text)
- ✂️ Precision trim, split, and reorder clips
- 🎨 50+ cinematic color filters (all free)
- 🔄 30+ smooth transitions
- ⚡ Speed control (0.1x – 10x)
- 📝 Text overlays with fonts and animations
- 🎵 Music library + voiceover recording
- 📤 720p & 1080p export — no watermark, no login required
- 📐 Aspect ratio presets: 9:16, 16:9, 1:1, 4:5
- 🤖 AI auto-captions (on-device, no cloud)
- 🔐 Privacy-first: all processing stays on your device
- 🔥 Firebase backend with cloud sync (optional)

### Technical
- Kotlin + Jetpack Compose + MVVM + Clean Architecture
- Media3 Transformer for hardware-accelerated export
- ML Kit Selfie Segmentation for background removal
- Whisper ONNX for on-device speech recognition
- Hilt dependency injection
- Room database for local project storage
- RevenueCat for subscription management
